# Realejo

Aplicativo da família **Tangram Educativo** para escrever, sortear e compartilhar notinhas. Quem recebe gira a manivela e o periquito entrega o bilhete.

- [Abrir o Realejo](https://joaofaustinojr.github.io/Realejo-/)
- [Portal de projetos](https://joaofaustinojr.github.io/-portal-de-projetos/)

## Créditos

Idealização e desenvolvimento por **João Faustino da Silva Júnior**. O rodapé do aplicativo identifica o projeto como **Tangram Educativo**.

O tema **Clássicos** apresenta excertos de obras em domínio público com os respectivos créditos de autoria e obra nos bilhetes.
